# Providers

All data sources are **read-only** — the integration only fetches prices,
never submits anything back.

| Provider | What it gives you |
|---|---|
| **Gas Wizard** (Affordable Energy) | Daily forecast: today's price + tomorrow's predicted price |
| **CityNews** | Daily price-change forecast from CityNews articles; Calgary and Halifax report the current average price (Calgary via a GasBuddy widget, Halifax via static regular+diesel tables) |
| **GasBuddy** | Live per-station prices, per fuel grade |
| **NRC Weekly** (Natural Resources Canada) | Official weekly average retail price per city — a reference anchor, not a forecast |

City lists are verified at install/upgrade time: cities whose site has no
gas-prices page (e.g. Edmonton, Vancouver, Montreal, Winnipeg) are
automatically excluded from the dropdown. Halifax's page uses a non-standard
slug (`halifax-nova-scotia-gas-diesel-prices/`) and reports current prices
plus diesel -- no forecast.

The Gas Wizard city list is built live from gaswizard.ca's sitemap.
**Burnaby** is the only sitemap page without forecast data, so it is excluded
automatically -- if its page ever gains data, or gaswizard.ca adds new
cities, they appear on their own after a reinstall or upgrade. No need to
file an issue asking for a city to be added.

**Request politeness:** the integration only ever *reads* from sources.
The city list is cached for a week, so sitemap + verification requests run
rarely; only not-yet-verified cities are probed (usually just Burnaby --
a single request), sharing one connection with a politeness gap between
probes. Every provider declares its `robots.txt`; the global rule is
`max(Crawl-delay, 1 second)` between requests, applied to probes,
retries and fetches alike. Price fetches are cached (15 minutes by
default, adjustable per entry), a manual refresh fetches once per
provider and then greys out for 60 seconds, and automatic retries are
capped at 5 per provider per day.

## Units

Everything is in **cents per litre (¢/L)** — the number on Canadian pumps.
GasBuddy's API already reports ¢/L, so the value is passed through raw;
the `¢/L` unit label carries the meaning.

## Finding a GasBuddy station ID

1. Open https://www.gasbuddy.com/gaspricemap
2. Click a station's price bubble, then through to its page
3. The ID is the number at the end of the URL
   (`.../station/205748` → `205748`)

Enter one or more IDs comma-separated, pick fuel grades (Regular, Midgrade,
Premium, Diesel) — one sensor per (station, grade).

## Refresh behaviour

- Forecast providers poll every 4 h (cache threshold 240 min default);
  GasBuddy every 30 min; NRC Weekly once a day (the source itself moves weekly).
- Failed fetch + cached data → GasBuddy keeps showing the last known value
  with `stale: True`; forecast providers show `unknown` (never stale forecasts).
- Rate limiting (HTTP 429 / 403) is tracked separately from generic failures;
  the Update status sensor suggests raising the cache threshold when
  automatic polls get throttled.
- Two-layer retry, both anti-abuse by design:
  - *Transport layer:* transient 429/5xx responses are retried in place
    (up to 2 attempts), honoring the server's `Retry-After` header.
  - *Application layer:* a persistently failed fetch is retried
    automatically per provider with backoff 15 → 30 → 60 → 60 minutes,
    capped at 5 retries per provider per day (counter survives restarts).
    The manual-refresh button cools down for 60 s after each press.

## NRC Weekly reference

Natural Resources Canada publishes the official weekly average retail
price for 71 Canadian cities (regular gasoline, taxes included). The
**NRC Weekly Average** sensor reports the latest *completed* week's
average for your city, with the week-ending date and the tax/margin
breakdown as attributes.

It is a **reference anchor, not a decision signal**: the number is
inherently lagged (up to a week old by design), so it answers "is
today's pump price high or low against the official average?" — not
"should I buy now?" (that's the Buy-now sensor's job). No forecast and
no Buy-now sensor are created for NRC devices.
